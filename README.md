# 업무 스케줄러 (Work Scheduler)

망분리(오프라인) 환경에서 **단일 HTML 파일**로 단독 실행되는 개인 업무 스케줄러입니다.
외부 의존성(CDN·라이브러리·서버) 없이 동작하며, iPad/PC 브라우저에서 바로 열어 사용합니다.

## 주요 기능
- **영업일(주말 제외) 기준 역산** — 타겟 완료일에서 단계별 소요일을 역산해 최소 시작일 계산
- **타겟 이전 / 타겟 당일 / 타겟 이후** 3단계 시점 구분 (당일 = 레드 강조)
- **스케줄 최적화 제안** — 병행 가능·업무 집중·즉시 착수·마감 위험·묶음 처리
- **캘린더 뷰** + 일자 클릭 상세 팝업
- **단계/세부내용 계층 체크** (하위 전부 체크 시 단계 자동 완료)
- **출력/백업** — PDF(인쇄), Excel(.xlsx, 라이브러리 없이 순수 JS 생성), CSV, JSON 백업/복원
- 다크모드 · 미래지향 디자인 · 중요도/긴급도 가시성 강조

## 사용법
- `scheduler.html` 을 브라우저에서 열면 끝. 데이터는 브라우저 `localStorage`에 저장됩니다.
- 데이터 보존을 위해 앱 내 **JSON 백업**을 주기적으로 받아두세요.
